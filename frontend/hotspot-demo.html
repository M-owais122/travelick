Step 3: What to Look For in the 360° View

Navigation Hotspots (Room to Room)

Green circles with arrows

These move you between rooms (Kitchen, Bedroom, Bathroom)

Object Hotspots (Furniture Details)

Colored circles with object icons

These show furniture/object details and 3D models

Step 4: How to Use Object Hotspots

1

Look Around the 360° View

Use your mouse to drag and look around the panoramic view. Object hotspots will be positioned on furniture.

2

Click on Object Hotspots

When you see a colored circular hotspot with an icon, click on it to see object details.

3

Explore the Object Modal

A popup will show with three tabs: Details, 3D View, and Gallery. You can see prices, specifications, and interactive 3D models.

4

Toggle Object Highlighting

Use the cube icon in the toolbar (right side) to turn object hotspots on/off.

If You Don't See Hotspots:

  • Make sure you're in the Living Room scene (first scene)
  • Look around by dragging your mouse in the 360° view
  • Check if the cube icon in the toolbar is highlighted (object highlighting enabled)
  • Refresh the page and wait for all scripts to load
  • Open browser console (F12) to check for error messages
